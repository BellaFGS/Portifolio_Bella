## 📖 Sobre o Projeto

A aplicação é uma interface estática executada diretamente no navegador. O projeto utiliza **React com Vite e TypeScript** na estrutura de desenvolvimento, além de CSS customizado e JavaScript para as interações visuais.

### 💻 Visão Geral & Funcionalidades

- **Hero:** Apresentação pessoal, chamada para download do currículo e links para redes sociais.
- **Sobre Mim:** Resumo profissional e indicadores de experiência.
- **Projetos:** Projetos em destaque apresentados como fases de um jogo.
- **Trajetória:** Linha do tempo com experiências profissionais e formação acadêmica.
- **Conhecimentos & Interesses:** Cursos, certificações e hobbies.
- **Contato:** Link direto para envio de e-mail e redes adicionais.
- **Responsividade:** Menu hambúrguer adaptado para dispositivos móveis.
- **Tema:** Alternador dinâmico entre modo escuro e modo claro.

## 🛠️ Tecnologias Utilizadas

- **Core:** [React](https://react.dev/), [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Estilização & Scripts:** HTML5 semântico, CSS3 customizado, JavaScript moderno (ES6+)
- **Recursos:** Google Fonts
- **Hospedagem / Deploy:** GitHub Pages
